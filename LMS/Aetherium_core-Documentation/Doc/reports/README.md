# Reports — denní zápisky

Historické denní reporty z vývoje zůstávají v této složce (originály z repozitáře).

Hlavní strukturovaná dokumentace je o úroveň výš v `Doc/*.md`.

Doporučený formát nových reportů:

```markdown
# YYYY-MM-DD Report

## Hotovo
- ...

## Rozpracováno
- ...

## TODO zítra
- ...

## Dopad na dokumentaci
- které soubory v Doc/ aktualizovat
```
